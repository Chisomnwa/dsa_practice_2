- Sliding Window
- Stack

- Linked List

- Heap/Priority Queue
- Backtracking
- Tries
- Graphs
- Advanced Graphs
- 1-D Dynamic Array
- 2-D Dynamic Array
- Greedy
- Intervals
- Math and Geometry
- Bit Manipulation

I have an older repository that contains my solutions to [DSA problems](https://github.com/Chisomnwa/dsa_practice) as well. This current repository is my continuation of that effort.
